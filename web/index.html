1-Wire sensors

AddressReadingUsed asStatus

DS18B20 sensors on pin D3, read every 5 seconds without blocking the OpenTherm loop. The assignment is stored in flash. Both sensors are used only when both read 0–60 °C; otherwise flow and return both come from MQTT. Without either the D1 replies DATA-INVALID.

Device

–
The E-CV switches in 7 steps, so "modulating" matches the spec. Compare the Elga's behaviour in the traffic log before keeping it.
Without a flow temperature the modulation stays 0 %. When reported, the Elga sees the fault bit (ID 0) and OEM fault code 25 (ID 5).

Firmware update

Running v–
PlatformIO builds it at .pio/build/d1_mini/firmware.bin. Settings are kept.

Erase settings

Erases WiFi, MQTT, the admin password and the sensor assignment. The D1 restarts with the setup hotspot. Pressing the reset button twice within 3 seconds also starts the hotspot, with the settings kept.
